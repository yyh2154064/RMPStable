# v0.4.5 实况地图绘画（待手动验收）

原版 NMapDrawings 在本地立即 BeginLine／UpdateCurrentLinePosition，随后才排队同步网络数据。本轮沿用这一顺序：实况输入先调用原版绘图方法生成临时原生展示，再提交来源校验；来源的原版结果到齐后移除临时展示。临时 DrawingState 不进入原版绘图集合、存档或权威状态，不预测对局结果。

使用原版 map_drawing.tscn、SubViewport、Line2D、墨水／橡皮材质、画笔图标及热点。坐标依次经过当前客户区、视口和地图全局变换；保留同帧内每个 WM_MOUSEMOVE，不只采样最后一个点。移动点最多 64 个一批传输，松开有预留队列容量。笔画带唯一来源标记，只有自身笔画权威结束回声才结束临时展示；房间／代次变化、权限撤回、拒绝和销毁均清理临时展示。绘图流的请求编号与其他操作等待编号分离，避免绘画后 F4/F5 等待错误回复。
