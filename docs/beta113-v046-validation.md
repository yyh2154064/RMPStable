# v0.4.6 兼容与启动专项

候选基于 v0.4.5。专项入口为 [Test-Beta113Startup.ps1](../tools/Test-Beta113Startup.ps1)。测试使用 F 盘隔离游戏、独立档案、Windows 原生游戏窗口和 localhost ENet。对照组使用同一测量探针，关闭 RMPStable。启动帧 P95 从探针初始化开始统计，进程到菜单使用外部时间。每轮选角记录从点击开始到按钮可用，并继续采样 120 帧。证据目录以 F 盘开发根为起点，完整日志留在本机。

## 构建与性能

- v0.107.1、v0.111.0、v0.113.0 兼容程序集和引导 DLL 均完成编译，零警告、零错误。v0.113.0 实际加载引导和功能程序集。两个旧版缺少本地匹配 PCK，运行时验证仍待完成。
- 已核对候选 DLL SHA-256 `DB847A5671DA6D4D46E4D9575D1CE40BB6BF535B163317F81800D6F32D1E2A8D`。ZIP 内容与候选文件夹的五个文件一致。v0.4.5 自带更新器使用模拟 GitHub 响应成功安装 v0.4.6 DLL、PCK 和清单，三个文件哈希均一致。
- 最终候选的三组交错对照中，启动到选角的六次运行均未创建副本。以下为各组中位数，证据为 `evidence/beta113-startup-20261113-141353-512`。同机另一轮中间候选实测到主菜单多约 1.20 秒，保留为启动差距随轮次变化的观察。

## 联机和新内容

- 联机专项按原版流程建房、加入、准备并进入开场房间，打开另一名玩家的实况并核对原版副本状态。逐端验证原版大厅包可编码和解码第 16 席位，房主大厅容量为 16。
- Blitz 固定种子专项在房主选取药水奖励项、跳过奖励选择，并确认消费商店次数。客户端收到原版购买同步，实况副本状态校验通过。证据为 `evidence/beta113-startup-20261113-141205-183`。
- Standard 双端进入新版 `EVENT.WUPPY_IN_TROUBLE` 并同步原版事件界面。证据为 `evidence/beta113-startup-20261113-141240-092`。
- Dread 双端进入开场事件，双方均成功核验对方的实况副本。三个联机专项中双端冷启动实况用时约 14.73–17.54 秒。Dread 证据为 `evidence/beta113-startup-20261113-141316-199`。
