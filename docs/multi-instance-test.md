## 本轮修复与边界

- 看牌页面识别原版 `NCardGrid`，不再仅识别 `NScrollableContainer`。Windows 滚轮的屏幕坐标转换为副本客户区坐标；独立牌组/战斗牌堆浏览直接滚动副本原版控件，观战模式也可用。
- 地图每格滚轮为原来四倍，连续输入先保留并合并，在主进程确认当前状态可操作后再发出。仍使用原版滚动插值和边界，不直接改地图数据。
- 原生待选择状态覆盖正在等待完成的卡牌/卡组选择器、目标、模态窗口与手牌选择。工具箱的战斗初始化三选一不会再被当作尚未结束的战斗动画。相同选择机制可复用，但没有穷举全部遗物。
- F5 初始化遇到待玩家选择时先完成淡入；移除替换 `RoomFadeIn` 的捷径，保留原版转场收尾。恢复期间仍缩短原版 Cmd/tween 等待，正常战斗动画不变。
- 连续拖牌缓冲具体卡牌/目标对象，在最新状态一致且权威确认可操作后重新定位手牌索引并检查原版合法性。最多八张、八秒，轮次/代次/权限或选择页面变化时清除；已提交或缓冲的牌不再遮住下一张的命中。不会预测伤害、能量、随机结果，也不保证消除全部动画等待。
- 副本的地图选择重放原版画圈及选点特效，房间旅行仍只由主进程决定。
- 副本右键绘图松开时结束遗留的原版按住绘图助手；输入归还本体时也清理该助手。窗口区域阻止本体同时启动另一支画笔，保留原版工具栏的绘图模式。
- 窗口与外壳加载提示均移到下方居中，白字黑描边，呈现为字幕。
- 完整跟随本体指针、悬浮放大和查看页面仅作架构讨论，本轮没有新增跟随模式。可行路径及独立进程的动画时差边界见 `native-mirror-presentation.md`。

## 原版界面与数据归属

副本是独立的游戏进程，直接呈现自己的原版 NRun 和房间、弹窗、控件。沿用 .13 外壳的开关、观战/控制、固定、拖动、缩放及四边收纳。生产管道没有图片抓取、PNG、画面传输或父进程贴图；原生 HWND 是经 PID 认证、以源窗口为 owner 的独立 popup，不使用跨进程 SetParent 或修改对方窗口过程。

主进程是唯一游戏权威。原版存档检查点和有序原生操作日志重建副本，保留原版 hook、随机数、奖励及选择任务。副本拖牌调用原版 NPlayerHand / NMouseCardPlay，由原版目标类型决定红色箭头；提交在主进程验证后调用原版出牌流程。地图、绘图、奖励、商店、事件、火堆、宝箱、选牌及下一章节均使用原版场景；跨进程控件通过稳定的类型、层级及卡牌语义键定位，不复用 Godot instance ID。奖励选牌候选由主进程原版序列化数据校准。

本机命名管道仅允许当前 Windows 用户。验证 session、密钥、PID、游戏/payload MVID、序号、generation、玩家与控制 epoch。提交时重新校验权限、原版状态、事件数和目标合法性；等待主进程结果及同步，不预测结算。任何过期状态、不同 hash、版本差异或断线都会阻止控制。

空闲点 hash 包含原版持久化对局状态，战斗中另包含 NetFullCombatState。副本自身 hover 产生的档案发现标记、运行时间和读档统计不属于游戏决策，归一化时仅处理序列化副本，不改真实存档。非战斗不比较已结束战斗留下的临时 CombatManager 对象。地图绘图另行核对。该校验不能证明所有动画、UI 时序及其他 mod 自定义字段一致。

本地设置、继续和牌库查看沿用原版展示控件；保存退出、放弃、图鉴、SL 由主进程处理真实对局。主进程原版菜单/确认框出现时隐藏副本和面板外壳，关闭后恢复。副本不能自行保存或放弃真实游戏。

## 恢复与进程隔离

主菜单和单人对局提前预热副本。F8 隐藏保留进程、认证和同步；单人 F5 撤销旧权限后保留进程，提前发布原版保存检查点，使两端并行恢复。恢复期间缩短原版等待和淡入，正常对局仍使用原版动画、模型、hook 与 RNG。读档后必须同时满足状态一致、原版可操作阶段、窗口可见、已绘制、当前控制权限生效以及首个合法操作被接受。

副本使用独立 APPDATA / LOCALAPPDATA、随机会话目录、force-steam off、静音及独立设置。只读取非运行解锁资料；不使用玩家当前局、历史或 Quick SL 文件。隐藏继续同步会占用资源。源退出、身份更换或进入多人时仅回收本次认证的精确子进程，不按进程名结束其他游戏。

120 FPS 为配置目标，实际帧率取决于两份游戏的负载。尚未验证朋友联机和其他 gameplay mod 一致性；v0.107.1 通过编译，运行验收针对 v0.111.0。典型流程回归不等于穷举所有卡牌、遗物、事件组合，也不替代全屏、高 DPI、Alt-Tab、收纳和物理鼠标 hover 的实际使用确认。
