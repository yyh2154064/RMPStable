# 单人本地观战测试版

分支：`liveSharingTest`。模组版本：`0.3.9-liveSharing.1`。

## 安装与使用

1. 退出游戏，备份现有 `mods/RMPStable` 中的 DLL、PCK 和 JSON。
2. 将测试 ZIP 内的 `RMPStable` 文件夹放到游戏的 `mods` 目录，覆盖这三个文件。
3. 启用模组，进入单人游戏。在游戏窗口按 **F8** 打开独立观战窗口，再按一次关闭；窗口右上角的关闭按钮也可以退出。
4. 在游戏 **设置 → 输入** 中找到 **本地观战窗口（单人测试）**，可以修改快捷键。设置沿用游戏原生保存与冲突处理机制。
5. 点击观战窗口顶部的原版牌组图标，可以浏览本地只读牌组；再次点击返回当前页面。悬停卡牌可以放大查看。

每次启动和每次新一局均默认关闭。退出单人局、换局或进入多人游戏时自动关闭。本阶段没有多人传输功能，联机时不会开启这个原型。

测试包不附带正式版的 `update.cmd`，以免更新时被正式版替换。恢复正式版时，覆盖回备份的三个文件即可。

## 已实现的显示

- 原版顶部状态栏、生命、金币、药水槽、遗物和牌组数量。
- 战斗背景、角色与敌人的视觉资源、当前手牌及扇形布局。
- 游戏已经公开显示的敌人意图与伤害数字，不预测后续行动。
- 原版血条边框、生命值填充、格挡盾牌及状态图标；读取当前原版显示的尺寸、字体和颜色。
- 战斗能量球、抽牌堆、弃牌堆、消耗堆和结束回合的只读外观。
- 商店背景与地毯、原版商品分区、价格、金币图标、折扣标签、遗物、药水和删牌服务图案。
- 抓牌候选的原版卡面与位置、遮罩、标题和额外选项文本。

当前页面和牌组中的所有游戏操作仍在原游戏窗口完成。观战窗口不提供打牌、购买、删牌、抓牌选择或结束回合操作。

## 实现方式

`LocalSpectatorSource` 读取当前单人局和已存在的原版显示节点，将需要的信息转换为不含 Godot 对象或游戏模型的 `SpectatorSnapshot`。打开窗口时每 250 ms 更新一次，并经过 JSON 序列化、反序列化后交给 `SpectatorView` 绘制。

卡牌复用原版 `NCard` 视觉预制体，但始终保持 `Model == null`。角色和敌人只实例化 `NCreatureVisuals`。商店、血条和状态栏读取原版纹理、九宫格边框、字体、位置、颜色等数据，重建为独立的显示节点。骨骼背景只重建绘制节点，不复制原版脚本、信号或业务对象。

参考原版的 `NCard`、`NMerchantSlot`、`NMerchantCardRemoval`、`NCreatureStateDisplay`、`NHealthBar`、`NTopBar` 和 `NCombatUi` 的实现。显示与操作逻辑混合的节点没有整体复制，例如原版删牌节点的购买回调和血条的生物事件订阅均没有接入观战窗口。

关闭时不采集游戏场景，不创建第二套显示节点。开启时需要额外的窗口、卡牌和骨骼动画渲染资源；窗口失去焦点时，原游戏的后台帧率、静音设置仍然生效。

## 当前边界

- 支持针对 v0.107.1 和 v0.111.0 分别构建，通过引导 DLL 自动选择实现。实际图形运行验证使用本机 v0.111.0；v0.107.1 的运行效果仍需要在该版本游戏中验证。
- 保留原版主要布局和静态外观，角色使用待机动画，不同步攻击、受击、死亡动画、粒子、音效、屏幕震动或鼠标位置。
- 不承诺所有怪物变体的骨骼皮肤、临时染色以及第三方模组资源都完全一致。缺失资源会记录日志；读取异常时清空旧画面并提示状态不可用。
- 地图、事件、休息点等页面目前显示只读牌组与状态栏，没有完整复刻页面内容。商店商品来自已生成的本地库存，原型不会主动生成商品。
- 该 JSON 格式用于验证数据与显示的分离，不是最终网络协议；重复的资源和布局数据较多。

本地验证能证明：同样的一份快照，可以在独立窗口重建可用的只读界面。以后接入好友观战时，还需要发送角色状态以外的手牌、奖励、个人商店、页面类型与布局信息，并处理权限、游戏版本、资源匹配、更新顺序、断线和缓存；仅收到角色信息还不足以还原全部页面。

## 验证记录

v0.107.1 与 v0.111.0 两个目标均编译成功，零警告、零错误。最终安装包在 v0.111.0 隔离图形环境中通过 37 项检查，并对照商店、抓牌和战斗的原版截图核验布局；删牌图案、抓牌横幅和格挡盾牌已确认显示。

自动验证放在 `tests/LiveSharingSmoke`，使用隔离的非 Steam 测试目录和独立存档。测试模组不包含在安装包中。验证包含默认关闭、原生设置入口、F8 开关、自定义按键、商店/抓牌/战斗快照、敌人攻击意图、原版血条与删牌图标、JSON 往返、只读牌组、关闭及退局清理。

测试对比采集与绘制前后的角色存档信息、能量与手牌，并检查观战窗口中的原版卡牌没有游戏模型。图形模式额外生成原版与观战窗口截图，用于人工对照。这些截图仅是开发测试工具的输出，模组功能本身不截屏、不录屏。

本次短时测试没有观战功能异常或断言失败，但游戏启动仍记录 `Invalid Task ID`，退出时仍有引擎资源未释放日志；尚未通过长期游玩或原版对照运行确定这些日志的来源，不能据此认定长期性能与资源释放已经完全验证。
