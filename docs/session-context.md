## 后续可能用到的架构与入口

公开窗口支持单人及多人战斗观战、经来源授权的多人战斗控制，以及上述五类多人个人选择器。多人对局仍由原版房主排序并判定，所选来源验证控制操作并提供原版状态和结果；副本为独立 OS 进程中的原版界面。不要回退像素传输或手绘界面，也不能在同一进程建立第二个依赖原版单例的 `NRun`。多人操作校验权限、generation/epoch、事件进度、自身上下文、身份和原版合法性；不要重新引入全队空闲/hash 相等作为多人输入前提。副本不预测对局结果。独立 APPDATA/LOCALAPPDATA，测试只操作认证自有进程和隔离档案。

源码主要位于 `RMPStable/src/RemoveMultiplayerPlayerLimit/Features/LiveSharing`：

- `MirrorHost` / `MirrorJournal` / `MirrorState`：权威、检查点、操作与校验；`MirrorEnding`：原版最终结算。
- `MultiplayerMirrorSession` / `Network/RmpMirrorPacket`：多人订阅、房主路由、分片与来源元数据；`MultiplayerBattleControl` / `MirrorMultiplayerControl`：来源授权、合法操作、去重/心跳和副本输入；`MirrorMultiplayerReplay`：多人原版 Replay 身份和四类事件消费；`LiveSharingMultiplayer`：公开窗口及来源生命周期；`MultiplayerPersonalUi`：原版个人选择器与呈现。非战斗房间留待后续阶段。
- `MirrorRenderer` / `MirrorCardInput` / `MirrorKeyboard` / `MirrorPresentation` / `MirrorNativeUi`：输入和本地展示；`SpectatorCommands` / `SpectatorNativeUi`：本体执行与原版选择器。
- `MirrorProcess` / `MirrorProtocol` / `MirrorNativeWindow`：进程、通信、窗口；`LiveSharingController` / `SpectatorView`：生命周期及外壳；`Features/QuickSl`：SL。
