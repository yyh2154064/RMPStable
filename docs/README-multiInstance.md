# RMP Stable 0.3.9-multiInstance.17

单人及多人战斗原生窗口版。将整个 RMPStable 文件夹放入游戏 mods 目录，重启游戏加载新 DLL。候选文件夹更新不会替换游戏中已经加载的版本。

默认 F8 打开多人观战窗口，按真实队伍名单切换来源；初次默认观看其他队员，随后记住所选玩家。所有参与者需要相同游戏与 Mod 版本。F8 隐藏后继续同步，重新打开复用副本；标题栏重置只重建观战副本。原版全队立绘保留，所选角色在副本中位于最前，本体仍保持自己的观察身份。

本轮 `.17` 开放多人第三阶段战斗控制：点击窗口的控制按钮申请，所选玩家在自己的游戏中点击“允许本场战斗”后，窗口才能出牌、选择目标、使用药水、结束回合，以及操作原版手牌选择、升级、网格、战斗牌堆和三选一界面。控制自己的角色窗口可直接授权。操作送回所选玩家本体，经原版多人流程处理，再同步结果。

所选玩家仍可操作，并可随时点击“撤销控制”。切回观战、隐藏窗口、切换来源、重建副本、离开战斗或控制心跳中断超过约 15 秒会撤权；下一场战斗需重新申请。状态已变化的操作会被拒绝，等待刷新后再操作。每个来源同时允许一个控制者；药水支持原版自身、队友及敌方目标，暂不支持远程丢弃。

离开战斗会隐藏旧战斗并提示当前房间，地图、事件、奖励、商店、火堆、宝箱等多人非战斗页面尚未接通。多人控制不包含 SL、放弃或跨房间操作。其他特殊选择器、Steam 跨电脑、三名以上玩家及实际可见窗口仍需验证；第三阶段详情见 `docs/multiplayer-phase3.md`。自动化通过后仍等待用户手动验收，不自动重跑旧测试。

`.14` 的布局继续保留：默认窗口总高度为游戏画面的一半，贴右侧，顶部露出状态栏及遗物行，默认观战并固定展开。重置、图钉和关闭按钮统一尺寸、中心线及反馈；保留手动布局。

单人导航提供 7 个本机测试来源，名称为 Steam 昵称加序号；全部连接同一个本机信号，方便手动测试翻页和切换。未初始化 Steam 时显示“本机玩家”。用户名框加宽至容纳 8 个中文字符并加圆角；长昵称的完整内容可悬停查看。不可用箭头隐藏并保留位置，观战/控制按钮缩小，顺序为观战/控制、重置、图钉、关闭。这些测试来源不代表已实现好友远程连接。

以下为沿用的单人功能；多人支持范围以前述说明为准。单人商店金币不足时点击卡牌、遗物、药水或删牌服务，会执行原版失败反馈和商人台词；右键商店卡牌可在窗口内放大、查看升级版，右键遗物可打开原版详情。浏览不购买、不升级真实卡牌。结果与待验收状态见 `docs/session-context.md`。

- 窗口直接运行原版场景和控件，包括战斗、地图、火堆、商店、宝箱、事件、奖励及选牌；操作由主游戏执行，再同步原版结果。
- 拖牌沿用原版目标判定和鼠标出牌流程。防御、自身目标和全体目标牌不会被统一添加红色指针；需要指定敌人的牌才进入原版指向流程。
- 雕琢打击、转化使用原版手牌选择、确认及战斗恢复；本体鼠标选牌、取消重选与窗口选牌均记入操作同步。回放先等待对应原版选牌任务。火堆升级、商店删牌、奖励选牌等同样使用原版界面。
- 地图可选点、拖动、绘图和擦除；跨房间及进入下一章节会更新原版场景。
- F8 隐藏保留副本进程并继续同步。主菜单和进入单人对局时提前预热；F5 重用同一进程，主游戏与副本并行恢复，拒绝旧状态的请求。
- 暂停菜单中的继续、设置和牌库查看使用副本原版展示控件。放弃在窗口内显示原版确认弹窗，取消后继续游戏，确认后才请求本体放弃。窗口内 F5 和菜单 SL 同样先在副本确认，由本体执行一次。保存退出和图鉴仍交由本体处理。
- 药水弹窗沿用原版点击空白处取消的松开逻辑。对商人使用污浊药水时，原版直接打开库存的操作也会同步，避免本体进入地毯购物页而窗口留在商人房间。
- 三选一奖励和工具箱选牌支持鼠标右键打开原版卡牌放大界面，并可点击原版升级预览按钮。查看和关闭只改变窗口展示，不会替本体选择卡牌。
- 最终建筑师房间、胜利/失败结算、继续计分和返回主菜单均使用窗口内原版界面。结算采用本体最终记录和分数；窗口重建可以恢复结算页，返回主菜单后关闭窗口。
- 副本进程启动时不创建控制台，并先在屏幕外的隐藏宿主中创建原生窗口，避免原版将初始化窗口挪到桌面左上角闪现。随后挂接到观战窗口。
- 窗口中的抽牌堆、弃牌堆、消耗牌堆及牌组在观战/控制模式均独立浏览，不打开本体页面，返回后可以继续操作。牌组/牌堆滚轮按窗口缩放补偿移动距离，保留原版滚动动画；主窗口收到的窗口区域滚轮消息会转发给副本。地图滚轮每格为原版的 3.25 倍，比 .10 的四倍下调 18.75%，并累计快速滚动输入。
- 鼠标位于副本内容区域时，键盘消息送到副本；位于本体时由本体处理。一次按键的重复和松开保留最初接收方，避免移出窗口后按键卡住；F8 保留为本体控制窗口显示。副本读取原版有效按键映射，数字选牌沿用原版出牌/目标流程，方向键选目标或切换焦点、确认、结束回合及 Esc 返回按对应原生控件处理。对局决策仍经过本体校验。按键重映射和手柄的所有组合未逐一验证。
- 设置页滚轮在副本的原版滚动容器中处理；窗口设置、音量、画面及按键修改仅写入副本独立档案，不修改本体设置或朋友电脑。副本档案随进程重建会重新生成，不保证这些窗口偏好跨重建保留。本条设置与操控只适用于单人，多人支持范围以前述战斗说明为准。
- 洁净等抽牌堆/牌组选牌页的滚轮直接在副本原版控件中处理，浏览无需等待主机校验；选中卡牌仍由主机执行。网格卡牌按原版列表中的位置识别，避免同名牌、悬停置顶及滚动复用控件改变选择身份。
- 工具箱等使用原版卡牌选择器的开局选择可以操作；F5 恢复在等待玩家选择时先完成淡入，不再把选择任务当作必须等待的动画。
- 连续拖牌在短暂等待权威或上一张牌动画时缓存具体卡牌及目标，最多八张、八秒；轮次、房间、权限或选择页面改变时清除。提交前重新校验原版手牌及目标，不预测伤害或随机结果。
- 地图选择调用原版画圈/选点特效。右键松开与输入归还时结束遗留的按住绘图助手；窗口区域阻止本体另起画笔。
- 加载提示改为窗口下方居中的白字黑描边字幕。
- 本体看牌、关闭看牌页面和页面滚轮不进入游戏操作回放，避免副本找不到本体独立打开的页面而停止同步。
- 副本初始化后主动完成原版淡入，同步 Godot 窗口尺寸，并在首次显示时主动绘制三帧。日志记录显示尺寸、转场遮罩及输入等待状态；用户此前首次黑屏的实际效果仍需在原对局确认。
- 卡住、黑屏或同步失败时，可点击标题栏的“↻”重新同步；报错时窗口下方也有“重新同步”按钮。从权威检查点与操作记录重建副本，保留本体当前对局。F8 隐藏后重新打开会重建已报错副本；F5 确认后仍由本体执行 SL。恢复图标与观战/控制按钮垂直对齐，悬停提示放在标题栏上方，避免被副本原生窗口遮住。
- 重建回放保留原版开局选牌的防误点等待，避免恢复过程过早选牌被原版忽略。

恢复和交互的实测结果以本版本 docs/multi-instance-test.md 为准。.6 的 96 毫秒 F8、920 / 986 毫秒 F5 是历史基线，不代表本版本或所有遗物组合。首次启动游戏引擎和加载资源仍需要时间，其他机器及对局组合需实际验证。测试不会操作当前游戏、修改真实存档或移动系统鼠标。

历史单人运行验证覆盖 v0.111.0 的典型流程；本轮多人仅验证前述第三阶段战斗控制，v0.107.1 已通过编译。仍需实际使用确认全屏、高 DPI、物理鼠标 hover，以及未逐一枚举的卡牌、遗物和事件组合。其他 gameplay mod 和朋友联机尚未验证。隐藏窗口仍占用副本进程资源；120 FPS 为配置目标，实际帧率取决于机器负载。
