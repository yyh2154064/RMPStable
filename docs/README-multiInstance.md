# RMP Stable 0.3.9-multiInstance.10

本机单人多实例原生窗口版。将整个 RMPStable 文件夹放入游戏 mods 目录，重启游戏加载新 DLL。桌面文件夹更新不会替换游戏中已经加载的版本。

- 窗口直接运行原版场景和控件，包括战斗、地图、火堆、商店、宝箱、事件、奖励及选牌；操作由主游戏执行，再同步原版结果。
- 拖牌沿用原版目标判定和鼠标出牌流程。防御、自身目标和全体目标牌不会被统一添加红色指针；需要指定敌人的牌才进入原版指向流程。
- 雕琢打击、转化使用原版手牌选择、确认及战斗恢复；本体鼠标选牌、取消重选与窗口选牌均记入操作同步。回放先等待对应原版选牌任务。火堆升级、商店删牌、奖励选牌等同样使用原版界面。
- 地图可选点、拖动、绘图和擦除；跨房间及进入下一章节会更新原版场景。
- F8 隐藏保留副本进程并继续同步。主菜单和进入单人对局时提前预热；F5 重用同一进程，主游戏与副本并行恢复，拒绝旧状态的请求。
- 暂停菜单中的继续、设置和牌库查看使用副本原版展示控件。放弃、保存退出、图鉴及 SL 请求交给主游戏处理；主游戏显示菜单或确认框时暂时隐藏窗口及外壳，关闭后恢复。
- 窗口中的抽牌堆、弃牌堆、消耗牌堆及牌组在观战/控制模式均独立浏览，不打开本体页面，返回后可以继续操作。牌组/牌堆滚轮按窗口缩放补偿移动距离，保留原版滚动动画；主窗口收到的窗口区域滚轮消息会转发给副本。地图滚轮每格为原来的四倍，并累计快速滚动输入。
- 洁净等抽牌堆/牌组选牌页的滚轮直接在副本原版控件中处理，浏览无需等待主机校验；选中卡牌仍由主机执行。网格卡牌按原版列表中的位置识别，避免同名牌、悬停置顶及滚动复用控件改变选择身份。
- 工具箱等使用原版卡牌选择器的开局选择可以操作；F5 恢复在等待玩家选择时先完成淡入，不再把选择任务当作必须等待的动画。
- 连续拖牌在短暂等待权威或上一张牌动画时缓存具体卡牌及目标，最多八张、八秒；轮次、房间、权限或选择页面改变时清除。提交前重新校验原版手牌及目标，不预测伤害或随机结果。
- 地图选择调用原版画圈/选点特效。右键松开与输入归还时结束遗留的按住绘图助手；窗口区域阻止本体另起画笔。
- 加载提示改为窗口下方居中的白字黑描边字幕。
- 本体看牌、关闭看牌页面和页面滚轮不进入游戏操作回放，避免副本找不到本体独立打开的页面而停止同步。
- 副本初始化后主动完成原版淡入，同步 Godot 窗口尺寸，并在首次显示时主动绘制三帧。日志记录显示尺寸、转场遮罩及输入等待状态；用户此前首次黑屏的实际效果仍需在原对局确认。
- 卡住、黑屏或同步失败时，可点击标题栏的“↻”重新同步；报错时窗口下方也有“重新同步”按钮。从权威检查点与操作记录重建副本，保留本体当前对局。F8 隐藏后重新打开会重建已报错副本；F5 仍是本体 SL。
- 重建回放保留原版开局选牌的防误点等待，避免恢复过程过早选牌被原版忽略。

恢复和交互的实测结果以本版本 docs/multi-instance-test.md 为准。.6 的 96 毫秒 F8、920 / 986 毫秒 F5 是历史基线，不代表本版本或所有遗物组合。首次启动游戏引擎和加载资源仍需要时间，其他机器及对局组合需实际验证。测试不会操作当前游戏、修改真实存档或移动系统鼠标。

运行验收覆盖 v0.111.0 的完整典型流程；v0.107.1 已通过编译。仍需实际使用确认全屏、高 DPI、物理鼠标 hover，以及未逐一枚举的卡牌、遗物和事件组合。其他 gameplay mod 和朋友联机尚未验证。隐藏窗口仍占用副本进程资源；120 FPS 为配置目标，实际帧率取决于机器负载。
