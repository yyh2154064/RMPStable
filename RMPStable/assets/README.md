# RMP Stable asset source

This Godot 4.5.x source project contains the mod icon plus English and
Simplified Chinese localization. It does not write a PCK into the source tree.

Use `../../RMPStable-Packager/一键打包.cmd` to copy these sources into an
isolated work directory, import them with Godot, and place the generated PCK
only inside the release ZIP.
