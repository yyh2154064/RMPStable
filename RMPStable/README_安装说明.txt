RMP Stable v0.2.1
=================

适用游戏版本：Slay the Spire 2 v0.107.1
最大联机人数：16 人

这是一个独立模组，不依赖其他多人联机扩容模组。

安装：
1. 不要同时启用其他多人联机扩容模组；请在模组菜单中禁用冲突模组，
   或暂时将其文件夹移出 mods 目录。
2. 将整个 RMPStable 文件夹复制到：
   Slay the Spire 2\mods\RMPStable\
3. 所有联机玩家都安装并启用同一个 RMP Stable 版本。
4. 建议房主重新加载存档后再让其他玩家加入；首次验证建议新开一局。

内置功能：
- 将多人联机人数上限提高到 16 人。
- 扩展大厅协议、玩家槽位及多人场景布局。
- 提供难度缩放、商店、篝火、宝箱房与胜利流程适配。
- 删除导致 Reward ID 分叉的重复远端宝箱奖励生成器。
- 适配 v0.107.1 的 SeedHelper.GetRandomSeed 新接口。
- 使用 RMP Stable 自有图标，以及重新编写的简体中文、英文界面资源。

资源说明：
RMPStable.pck 是本项目用 Godot 4.5.1 构建的独立资源包。
DLL 中的本地化路径也已改为 res://RMPStable/localization/。

同步问题修复原理：
当前游戏版本会在宝箱房中一次性为所有玩家生成房间结束奖励。如果远端开箱消息
再次生成奖励，房主和客户端记录的 Reward ID 数量及顺序就会不同，并在切换楼层时
触发“多人游戏数据不同步”。本模组不会注册该重复奖励处理器。

启动日志应出现：
[RMP Stable] Initializing standalone v0.2.1 for STS2 v0.107.1...

验证建议：
使用 5～6 人新局，经过至少一个宝箱房后连续切换若干楼层。如果仍然发生不同步，
请同时保留房主和至少一名客户端的同一局日志。

注意：当前成品已完成源码编译、程序集反编译回查与静态兼容验证；真实 5 人以上
联机仍需多台客户端共同验证。
